# Weather Intelligence Dashboard v6

The dashboard keeps the previous layout and data features, but the atmospheric background is upgraded.

Rain mode now uses:
- three depth layers of rain for a 3D/parallax feel
- different streak sizes and speeds
- subtle mist and ground-splash texture
- moving cloud layers
- wind-inspired diagonal rain direction
- separate day/night behavior

Clear, cloudy, snow and night scenes remain dynamic.

Run `index.html` with VS Code Live Server. Internet is required for live weather data.
